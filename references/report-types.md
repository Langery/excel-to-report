# 四类材料详解

## 1. 周报初稿（weekly-report）

**何时用**：用户说"写周报"、"汇总本周"、"本周工作总结"，且表格里有日期列。

**结构**：
1. 本周概览（1-2 句：总量 + 环比口径，若表中只有单周数据则只报总量）
2. 按维度分组的量化呈现（每组：做了多少件/合计金额/平均耗时，数字来自 --group 统计）
3. 重点事项（数据量最大的 1-3 组，各展开一句事实描述）
4. 异常与风险（若同时生成异常清单，摘 1-2 条最关键的）
5. 下周计划（**表格里通常没有**——留空让用户填，标注【待补充】）

**口径确认**：周期是自然周还是用户自定义？是否含周末？

## 2. 工作汇报段落（briefing）

**何时用**：用户说"跟领导汇报"、"写段话"、"邮件里怎么说明"，表格数据较单一（1-2 个数字维度）。

**结构**（3-5 句，100-200 字）：
1. 结论句：核心数字 + 一句话判断（"本月共处理 XX 件，完成率 XX%"）
2. 支撑句 1-2：次级数字，说明结构或趋势
3. 说明句：口径说明或需要领导知道的事项（表格里有的才写）
4. （可选）请求句：需要什么支持——仅当用户明确说有诉求时加

**禁忌**：不用形容词堆砌（"成效显著""稳步推进"），让数字自己说话。

## 3. 分类叙述（category-narrative）

**何时用**：用户说"按 XX 划分"、"分类说明"、"每个部门/月份/状态的情况写一下"。

**结构**：
- 开头一句总述：划分维度 + 组数 + 总量
- 每组一段（2-4 句）：组名 + 该组核心数字 + 组内值得一提的事实（最大值/最小值/占比）
- 组的排序：按数量降序，除非用户指定
- 结尾一句：组间对比的最大差异（"占比最高的 A 组是最低 F 组的 X 倍"）

**组数超过 8 组**：正文写 Top 5，其余合并成一句"其余 N 组合计 XX 件，占比 XX%"。

## 4. 异常项清单（anomaly-checklist）

**何时用**：用户说"有什么问题"、"检查一下"、"哪些不对劲"，或表格质量明显可疑（空值多、数字离群）。

**检查项**（按优先级）：
1. **空值/缺失**：关键列（日期、金额、负责人）的空值行，点名行号
2. **超期**：有截止日期列 + 完成状态列时，找出"未完成且已超期"的行
3. **离群值**：数值列明显偏离的记录（高于均值 3 倍以上或为 0/负数的金额）
4. **重复**：关键列完全重复的行
5. **格式混乱**：同一列里日期格式不一、文本数字混写

**输出格式**：表格（编号 | 位置 | 问题 | 原始值），每条一行，末尾一句修复建议。**只点名，不改表。**

## 组合策略

用户没想好要哪种时，按表格形态给默认组合并在交付时说明：
- 有日期 + 状态列 → 周报初稿 + 异常清单
- 只有状态/类别列 → 分类叙述 + 异常清单
- 只有数字列 → 汇报段落
